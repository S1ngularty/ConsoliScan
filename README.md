# ConsoliScan

A modern retail Point-of-Sale (POS) system for Philippine retailers featuring AI-assisted product scanning, offline-first transactions, inventory management, and government subsidy verification.

## Overview

ConsoliScan is a full-stack retail management platform designed to simplify store operations while supporting government subsidy programs. It provides an efficient checkout process, accurate inventory tracking, role-based access control, and offline capabilities to ensure reliable operation even with limited internet connectivity.

## Features

* Retail Point-of-Sale (POS)
* AI-assisted barcode and product detection
* Real-time inventory management
* Offline-first transactions with automatic synchronization
* Government subsidy eligibility verification
* Role-based access control
* Loyalty rewards system
* Sales analytics and reporting
* Blockchain-based transaction audit trail

## Significance

ConsoliScan combines retail automation, artificial intelligence, and government service integration into a single platform. Its offline-first architecture allows stores to continue operating without interruption, while AI-assisted product recognition and real-time inventory management improve efficiency and accuracy. The system also promotes secure, transparent, and scalable retail operations through role-based security and blockchain-backed audit logging.
